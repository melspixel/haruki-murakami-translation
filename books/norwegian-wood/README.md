# 《挪威的森林》中文注释精校版

这是村上春树《ノルウェイの森》的简体中文译本。

本翻译以还原日语母语读者阅读原著时的感受为目标。除了准确传达基本意思，也尽量保留人物之间的距离、说话的轻重、停顿、幽默、克制、节奏和留白。现有中文译本只作参考，最终措辞以日文原文和完整语境为准。

全书经过逐句中日对照审校，重点检查了日语省略主语和宾语后容易出现的指代、说话者、动作关系和称谓问题。完成后又脱离日文连续通读中文，对不自然的语序、搭配、对话和段落衔接进行了修改。

人物姓名按日文原名处理，例如「小林緑」译作“小林绿”，不使用“小林绿子”。书中的音乐、文学作品、历史事件和时代背景也经过核对，最终加入65条简短注释，只说明理解正文所需的信息。

电子书重新制作了封面、目录、正文排版和 Kindle 兼容脚注。最终文件经过正文反向核对，并通过 EPUBCheck 5.3.0 检查，没有发现结构错误或兼容性警告。
