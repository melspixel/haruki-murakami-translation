# 《国境以南，太阳以西》中文精校版

这是村上春树《国境の南、太陽の西》的简体中文译本。

本翻译追求的是：忠实，自然，准确传达原文的意思，尽可能保留村上春树笔下特有的节奏、克制、疏离感和没有说尽的部分。译文力求让中文读者获得接近日语读者的阅读感受。

全书经过逐句中日对照审校。翻译过程中重新核对了人物关系、说话者、主语指代、对话归属和前后文联系，并在完成后脱离日文连续通读中文，对不自然的表达、人物声线和段落节奏进行了进一步润色。

书中涉及的音乐、电影、歌词、典故和时代文化信息也经过重新检查，最终加入44条简洁的译者注。注释只补充理解作品所需要的信息，不解释人物动机，不替读者解读象征，也不打断小说本身的留白。

电子书重新制作了封面、目录、正文排版和 Kindle 兼容脚注。正文与对话段统一缩进，中文字体由阅读器决定，默认优先使用苹方。最终文件通过 EPUBCheck 检查，没有发现结构错误或兼容性警告。
